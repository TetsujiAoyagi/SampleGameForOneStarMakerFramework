# ドキュメント方針

正本は `docs/README.md`。この参照を使う作業では、先に正本を全文読む。公開面には今この瞬間に真で、第三者がcloneして確認できる内容だけを置く。

## 更新規則

- 古い説明と新しい説明を併存させず、現況へ置き換える。
- 公開文書のファイル名に日付を入れない。
- 「これは読むな」と注記して残さず、不要なら削除する。
- 公開面から、正本が定義する手元層や個別 HANDOFF を参照しない。
- 恒久的な設計文書を新設する前に、既存文書の置換・統合で済まないか確認する。
- Phase B は HANDOFF に指示されていない設計文書を独自に増やさない。

変更後は `pwsh tools/docs-audit.ps1` を実行する。

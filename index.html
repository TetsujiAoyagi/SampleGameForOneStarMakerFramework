OSM の実測記録

OneStarMaker（OSM）の配布単位の設計のために、Unity 6000.6 の Content Directory の挙動を Editor の Play で実測した記録です。新しい順に並べています。

2026-11-14
prefab を編集して build し直すと、Scene に古い prefab が残る
差分 build の判定が Scene の file だけを見ている。印の方式で、cache を捨てずに回避できた。
2026-11-14
取得した build に、手元で build した上書きを重ねて登録する
base → 上書きの順なら上書きの版が読まれる。逆の順では効かない。
2026-11-12
同じ file を持つ 2 つの Content Directory を同時に登録すると何が起きるか
Loadable からは実体 1、Scene の直接参照からは 2。後から登録した側の解除が、黙って物を壊す。

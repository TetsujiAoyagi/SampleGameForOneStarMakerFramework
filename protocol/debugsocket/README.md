# DebugSocket protocol（YAML 正本）

Unity と DebugStudio が共有する **wire 契約の正本** です。MessagePack DTO はここから生成します。

## 開発者ルール（最短）

1. **生成された `*.cs` を手で直さない**（先頭に `// <auto-generated />`）
2. フィールド / Key / enum 値を変えるときは **この YAML を直す**
3. 再生成: `./tools/protocol-codegen/generate.sh`
4. 差分がないこと: `./tools/protocol-codegen/generate.sh --check`
5. 側固有ロジック（`FromRecord`、DS の `Kind` ビューなど）は **手書き partial** へ

## 新 message type の採番

- 共通（Unity + DS）: `messages.yaml` に追加し `surfaces: [unity, debugstudio]`
- CLI / DS 専用: `surfaces: [debugstudio]` のみ（Unity に漏らさない）
- **欠番の再利用禁止**。追加のみ。

## レイアウト

| パス | 内容 |
|---|---|
| `meta.yaml` | emitter 出力先 / namespace |
| `messages.yaml` | `DebugSocketMessageType` |
| `enums.yaml` | flags / enum |
| `envelopes/*.yaml` | 各 DTO |
| `fixtures/proto00/` | バイト互換 golden（PROTO-00） |
| `SCHEMA.md` | 型システムのメモ |

この YAML 群が wire 契約の正本であり、Unity 側 / DebugStudio 側の DTO は
`tools/protocol-codegen` がここから生成する。手書きで両側を編集しないこと。
